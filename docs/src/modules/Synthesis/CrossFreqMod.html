CrossFreqMod : Cross frequency modulation synthesis¶

Description¶

Based on pyo’s CrossFM object. Two oscillators modulate each other’s frequency. Carrier Frequency and Frequency Ratio set their frequencies. Carrier Index controls the carrier’s modulation of the other oscillator, while Modulator Index controls modulation of the carrier.

This module generates its own audio and requires no input sound file. In the routing view, it is a source module.

Parameter jitter¶

Each synthesis parameter has independent smooth random jitter. Amplitudes are relative: parameter * random(1 - amplitude, 1 + amplitude), clipped to the parameter range. For the FM modules, carrier jitter precedes polyphony pitch transposition.

Each jitter uses a pair of half-width amplitude and frequency sliders. Amplitude sliders are logarithmic, start at 0.0001, and use gliss=0.0 so their values apply immediately at initialization. Frequency sliders set the jitter rate in Hz.

Graph Only¶

Overall Amplitude controls the output amplitude over the performance duration.

Popups & Toggles¶

Polyphony Voices sets the number of simultaneous synthesis voices.

Polyphony Spread sets the pitch relationship between voices. Both polyphony controls are set at initialization.
